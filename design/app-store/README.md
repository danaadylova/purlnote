# App Store screenshots

Frames iPhone screenshots with a caption, at 1320 × 2868 (the 6.9-inch iPhone size App Store Connect asks for).

1. Take the screenshots on an iPhone and save them here as `screenshots/1.png` to `screenshots/5.png`:
   1. Notebook, with a project on the needles
   2. A pattern open in the reader, with the row ruler on
   3. Steps, with a size chosen
   4. A project page with notes and photos
   5. The hello page of the tour
2. `npm install`, then `npm run frame`. The framed images are written to `out/`.

The captions and background colours are at the top of `frame.js`.
